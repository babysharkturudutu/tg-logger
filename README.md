# Telegram Message Logger

Юзербот на базе Telethon с локальным веб-интерфейсом на FastAPI. Сохраняет входящие личные сообщения и ответы на ваши сообщения в группах, отслеживает удаление и редактирование сообщений, а также сохраняет медиафайлы.

## Возможности

- Сохранение входящих личных сообщений и реплаев на ваши сообщения в групповых чатах.
- Фиксация удалённых сообщений (помечаются отметкой `удалено`).
- История редактирования сообщений с возможностью переключения между исходным и изменённым текстом.
- Локальное сохранение и отображение медиа: фотографии, видео (с полноэкранным просмотром) и голосовые сообщения (со встроенным плеером).
- Быстрые фильтры в интерфейсе: `Все`, `Удалённые`, `Изменённые`, `С медиа`.
- Фильтрация сообщений по дате через встроенный календарь.
- Изоляция диалога с конкретным собеседником по клику на его имя или аватар.
- Поиск по тексту сообщений и чатам.
- Обновление интерфейса в реальном времени.

## Требования

- Python 3.10+
- Аккаунт Telegram и ключи API (`api_id` и `api_hash`)

## Установка

1. Клонируйте репозиторий или скачайте архив:
```bash
git clone https://github.com/username/tg-logger.git
cd tg-logger
```

2. Создайте и активируйте виртуальное окружение:
```bash
# Linux / macOS
python -m venv .venv
source .venv/bin/activate

# Windows (PowerShell)
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Настройка

Получите `API_ID` и `API_HASH` на сайте [my.telegram.org](https://my.telegram.org) в разделе «API development tools».

Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```

Заполните переменные:
```ini
API_ID=12345678
API_HASH=your_api_hash
HOST=127.0.0.1
PORT=8000
```

Если файл `.env` не создан, скрипт запросит `API_ID` и `API_HASH` в консоли при первом старте.

## Запуск

```bash
python app.py
```

При первом запуске потребуется ввести номер телефона и код подтверждения из Telegram для создания локальной сессии.

После запуска откройте в браузере:
http://127.0.0.1:8000

## Безопасность

Файлы `session.session` и `logs.db` содержат конфиденциальные данные (сессию вашего аккаунта Telegram и историю переписки). Не передавайте их третьим лицам и не добавляйте в публичные репозитории.
